# leetpulse

leetpulse is a productivity tool that helps you **retain coding problems better** using spaced repetition and the Ebbinghaus forgetting curve.  
It’s built for LeetCode users who want to practice smarter, not harder.

---

## ✨ Features

- Add problems with metadata (topic, difficulty, notes).
- Spaced repetition review system powered by **NextPulse algorithm**.
- AI-powered code feedback with complexity analysis and hints.
- Track stats like XP, levels, mastery count, and progress.
- Simple in-app IDE to practice and review problems.

---

## 🛠️ Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [Tailwind CSS](https://tailwindcss.com/)
- [MongoDB](https://www.mongodb.com/) with Mongoose
- [Google GenAI](https://ai.google/) for code analysis
